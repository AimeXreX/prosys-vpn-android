# Release signing backup

`prosys-release.jks` کلید انتشار ProSyS VPN است. رمز آن در `../V2rayNG/signing.properties` نگهداری می‌شود و هر دو مسیر توسط Git نادیده گرفته می‌شوند.

این دو فایل را با هم، رمزگذاری‌شده و در حداقل دو محل مستقل بکاپ بگیرید. آن‌ها را روی GitHub، سرور عمومی، پیام‌رسان یا داخل APK قرار ندهید. تمام نسخه‌های بعدی فروشگاه با همین کلید امضا می‌شوند.
