# راه‌اندازی ساده بک‌اند V2

ساختار سرور در V2 تغییر نکرده و همان مدل سبک نسخه اول است.

1. پوشه `backend` را روی سرور کپی کنید.
2. در همان پوشه `npm install` را اجرا کنید.
3. `.env.example` را با نام `.env` کپی و مقادیر 3x-ui و دامنه را وارد کنید.
4. سرویس را با `npm start` یا یک process manager مانند systemd/PM2 اجرا کنید.
5. فقط مسیرهای `/api/free/` و `/privacy` را در Nginx به `127.0.0.1:3010` بفرستید.
6. از `.env` و `data/free-devices.json` نسخه پشتیبان داشته باشید.

پشتیبان‌گیری دستی:

```bash
npm run backup
```

مسیر `/health` اکنون سلامت backend و دسترسی به 3x-ui را هم‌زمان بررسی می‌کند. پیام کوتاه اختیاری برنامه با `APP_NOTICE` تنظیم می‌شود؛ خالی‌بودن آن یعنی هیچ پیامی نمایش داده نشود.

مسیرهای رسمی ارتباطی:

- سایت: `https://vpn.prosysvpn.top/`
- ربات فروش: `https://t.me/ProSySsellbot`
- کانال رسمی: `https://t.me/Prosys_VPN`

فایل دیتابیس JSON برای یک process طراحی شده است. اگر بعداً چند نسخه هم‌زمان از backend اجرا شود، داده دستگاه‌ها باید به PostgreSQL یا دیتابیس مشترک دیگری منتقل شود.
